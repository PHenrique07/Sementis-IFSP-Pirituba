# Compatibilidade da skill com Codex

Esta entrada permite descobrir a skill sem duplicar suas instruções.

1. Abra e siga o [SKILL.md original](../../../.github/skills/using-agent-skills/SKILL.md) antes de executar a skill; este link não carrega o conteúdo automaticamente.
2. Resolva referências, scripts e assets a partir da pasta original .github/skills/using-agent-skills/, e não desta pasta de compatibilidade.
3. Aplique as orientações de [compatibilidade com Codex](../../../AGENTS.md#5-compatibilidade-com-codex), respeitando as ferramentas disponíveis e os papéis do esquadrão.
